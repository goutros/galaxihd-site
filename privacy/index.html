This website

galaxihd.com is a static site. It has no accounts, no forms that store data, and no tracking cookies of its own. Embedded content (like YouTube videos) follows that provider's own privacy policy.

Galaxi Vault Analytics

Galaxi Vault Analytics is a private tool used only by GalaxiHD to read analytics for the GalaxiHD YouTube channel. It is not offered to anyone else.

  • What it accesses: read-only YouTube Analytics and YouTube channel data for the channel owner's own account, through Google's official APIs.
  • How it is used: to build private performance reports for the channel. It never posts, edits, uploads or deletes anything.
  • Where it is stored: on the channel owner's own computer only. It is never sold, shared or sent to third parties.
  • Removing access: you can revoke access at any time at myaccount.google.com/permissions.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
